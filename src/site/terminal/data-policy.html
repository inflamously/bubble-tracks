Data policy

This site sets no cookies, stores nothing in your browser, has no analytics and no tracking, and loads nothing from other servers. The only data about you is what the host records when your browser asks for the page.

Who is responsible

The maintainer of bubble-tracks. You can reach them through the project's GitHub repository.

Hosting: GitHub Pages

The site is hosted on GitHub Pages, a service of GitHub, Inc. (USA) and GitHub B.V. (Netherlands). To deliver the page, your browser sends GitHub your IP address and the details of the request, such as the page asked for and your browser type. GitHub states: “the visitor's IP address is logged and stored for security purposes, regardless of whether the visitor has signed into GitHub or not”. GitHub does not say how long it keeps these logs, and the maintainer has no access to them.

The legal basis is Art. 6(1)(f) GDPR: the legitimate interest in delivering the site reliably and securely. According to GitHub, data sent to the USA is covered by the EU-U.S. Data Privacy Framework and standard contractual clauses. More in the GitHub General Privacy Statement.

The demo

The demo runs entirely in your browser. The commands you type and the files it shows live in this tab's memory and are gone when you reload or close it. Nothing you type is sent anywhere.

Links

The site links to the project's repository on github.com. Nothing is sent there until you follow the link; from then on GitHub's own privacy statement applies.

Your rights

Under the GDPR you can ask for access to your data, have it corrected, erased or its use restricted, object to its use, and complain to a data protection authority. The maintainer holds no data about visitors, so a request about the server logs has to go to GitHub.
